# Auto Mode Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development or superpowers:executing-plans to implement the focused tasks.

**Goal:** Add explicit, stoppable desktop click/type/scroll automation to Aether.

**Architecture:** A dependency-injected action engine drives a native Hyprland executor. Main owns one session and cancellation; renderer exposes Auto/Stop and status. Existing providers and evidence retrieval stay shared.

**Tech Stack:** Electron, Node, Hyprland Lua IPC, grim, ydotool; existing LLM adapters.

**Spec:** ../specs/2026-10-18-auto-mode-design.md

## Review focus

- User changes focus while a model/subprocess is pending: no subsequent input.
- Overlay overlaps a proposed click: reject the action.
- A model emits malformed or non-action text: fail closed.
- Cancellation races with countdown/model/input: no new steps after cancellation; no overlapping session.
- A form's appearance/labels are ambiguous: stop for user review; do not claim prompt checks guarantee every submission is detected.
